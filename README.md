<h1>Project: Rock Paper Scissors</h1>
You came to the dungeon to defeat evil monsters with your RPS strategy.<br>
This project is based on <a href="https://www.theodinproject.com/">The Odin Project</a>.

<h3>Features</h3>

- A rock-paper-scissors game with an RPG taste.

- The monsters get stronger as you descend into the dungeon.

- Responsive Design implemented.

<h3>Tech Stack</h3>

- Frontend: HTML CSS JavaScript

- Icons: <a href="https://pictogrammers.com/">Pictogrammers</a>
